AI 拍照辨識設定

「飲食紀錄」頁的拍照辨識功能使用 Google Gemini API（具影像辨識能力）。 金鑰只會儲存在你目前使用的瀏覽器中，並直接從瀏覽器送往 Google 的伺服器進行辨識，不會經過任何其他第三方， 也不會包含在「匯出資料」的備份檔中。請至 Google AI Studio 申請屬於你自己的 API Key。 Gemini 的 API Key 會附加在請求網址上，建議在 Google AI Studio／Cloud Console 為金鑰設定 HTTP Referrer 限制以降低外洩風險。 每次辨識都會呼叫 API，依你的方案可能產生費用，請自行留意用量。
